# طرنيب أونلاين — Trix Online

لعبة ورق عربية احترافية (طرنيب) بين 4 لاعبين، الشركاء متقابلان — مع نظام عضوية كامل، متجر، لوحة متصدرين، دردشة، أصوات وحركات.

- **الواجهة**: React 19 + TypeScript + Vite + Tailwind CSS 4 + Framer Motion (تصميم عصري، متجاوب، عربي RTL بالكامل)
- **الخادم**: PHP 8 + SQLite (جاهز للرفع على استضافة cPanel عادية)
- **التطبيق**: APK لأندرويد (بدون Android Studio — بناء مباشر من سطر الأوامر)

---

## 1) بنية المشروع

```
trix/
├── client/                  # واجهة React (SPA)
│   ├── src/
│   │   ├── screens/         # الشاشات: الدخول، الردهة، الطاولة، المتجر، الملف، الإعدادات
│   │   ├── components/      # مكوّنات اللعب (الطاولة، الأوراق، لوحات المزايدة، الدردشة)
│   │   ├── game/            # أنواع الورق + قوانين اللعبة + ذكاء البوتات + اللعب المحلي
│   │   ├── lib/             # الاتصال بالخادم، الصوت، حالة التطبيق، الجلسات
│   │   └── hooks/           # أصوات اللعبة والتنبيهات
│   └── dist/ | dist-android/  # مخرجات البناء (web / android)
├── server/                  # خادم PHP + SQLite (هذا ما يُرفع على cPanel)
│   ├── index.php            # نقطة الدخول: /index.php?r=<route>
│   ├── config.php           # إعداداتك (كلمة السر، بيانات القاعدة، التصحيح)
│   ├── install.php          # فحص التثبيت (يفتح في المتصفح)
│   ├── src/                 # الكود: Core (المصادقة، الغرف) + Game (المحرك) + Api (المسارات)
│   └── data/                # قاعدة بيانات SQLite (تُنشأ تلقائياً — اجعلها 755/775)
├── tools/
│   ├── dev/                 # أدوات التطوير: خادم PHP عبر WebAssembly + اختبارات
│   └── android/             # بناء APK: الأدوات + القالب الأصلي + أيقونات
└── release/                 # المخرجات النهائية (APK + حزمة الخادم)
```

## 2) تشغيل الواجهة محلياً

```bash
cd client
npm install
npm run dev          # http://localhost:5173
```

للاتصال بخادمك على cPanel أثناء التطوير، ضع الرابط في `client/src/config.ts`:

```ts
export const BUILT_IN_SERVER = 'https://example.com/trix';   // مجلد ملفات الخادم
```

أو اتركه فارغاً واضغط ⚙️ **الإعدادات** داخل التطبيق لإدخال الرابط (يُحفظ في الجهاز).

### تشغيل كل شيء محلياً بدون تثبيت PHP (اختياري)

```bash
cd tools/dev
npm install            # php-wasm
node php-server.mjs    # يخدم PHP + الواجهة المبنية على http://127.0.0.1:8095
node test-api.mjs      # اختبار كامل: تسجيل → غرفة → بوتات → مباراة كاملة
node test-routes.mjs   # تغطية شاملة لكل مسارات API (51 فحصاً)
node test-offline.mjs  # اختبار محرك اللعب المحلي (مباريات كاملة + فحوصات القوانين)
node calibrate-bots.mjs 400   # قياس أداء ذكاء البوتات (نسبة نجاح الطلبات)
```

### أدوات الحزم والبناء (من جذر المشروع)

```bash
node tools/package-server.mjs    # → release/cpanel-server.zip (خادم + واجهة ويب)
node tools/android/setup-toolchain.mjs   # تجهيز أدوات بناء APK (مرة واحدة)
node tools/android/build-apk.mjs         # → release/trix-android.apk
node tools/android/make-icons.mjs        # إعادة توليد أيقونات التطبيق
```

## 3) رفع الخادم على cPanel

1. من `release/cpanel-server.zip` استخرج الملفات إلى مجلد داخل `public_html` (مثلاً `public_html/trix`).
2. افتح `https://موقعك/trix/install.php` لمتابعة الفحص (صلاحيات المجلدات، إصدار PHP، SQLite).
3. عدّل `config.php`:
   - `secret` → مفتاح سري عشوائي طويل.
   - `debug` → `false` في الإنتاج.
   - `data_dir` → مجلد قاعدة البيانات (يُفضّل مجلداً خارج جذر الموقع إن أمكن).
4. تأكد أن مجلد `data/` قابل للكتابة (755 أو 775 حسب الاستضافة).
5. اختبر: `https://موقعك/trix/index.php?r=health` يجب أن يعيد `{"ok":true,...}`.

> لا تحتاج MySQL: قاعدة البيانات SQLite تُنشأ تلقائياً في `server/data/trix.sqlite`.

## 4) بناء ملف APK

### الطريقة السريعة (تعمل بالكامل من سطر الأوامر، بدون Android Studio)

```bash
cd trix
node tools/android/setup-toolchain.mjs   # ينزّل الأدوات (aapt2, d8, apksigner, ecj, JRE) مرة واحدة
node tools/android/build-apk.mjs         # يبني الواجهة + APK موقّعاً
# الناتج: release/trix-android.apk
```

الأدوات تُحفظ في `~/.cache/trix-android-toolchain` (تُنزَّل من npm و PyPI فقط).

مع تمرير التوقيع الخاص بك (اختياري):

```bash
TRIX_KEYSTORE=/path/my.keystore TRIX_KEYSTORE_PASS=secret \
TRIX_KEYSTORE_ALIAS=mykey TRIX_KEYSTORE_KEY_PASS=secret \
node tools/android/build-apk.mjs
```

### الطريقة المعتادة (Capacitor + Android Studio) — لم تعد مطلوبة

المشروع يبقى متوافقاً مع Capacitor إن أراد المطوّر البناء عبر Gradle:

```bash
cd client && npm run build:android && npx cap add android && npx cap sync android
```

### ما يحتويه التطبيق

- ملفات الواجهة مدمجة داخل `assets/www` وتُقدَّم عبر أصل آمن `https://trix.game/` (يعمل مع الذاكرة المحلية والشبكة).
- جسر أصلي: اهتزاز، تنبيهات، حافظة النسخ، إبقاء الشاشة مضاءة، تخزين دائم، زر الرجوع الذكي.
- صلاحيات: `INTERNET`, `ACCESS_NETWORK_STATE`, `VIBRATE`, `WAKE_LOCK`, `POST_NOTIFICATIONS`.
- `usesCleartextTraffic=true` للسماح بالاتصال بخادم HTTP بدون SSL (يُفضّل https).

### تغيير رقم الإصدار/الاسم

- الاسم والصلاحيات: `tools/android/shell/AndroidManifest.xml`
- رقم الإصدار (versionCode/versionName): نفس الملف و `tools/android/build-apk.mjs`
- الأيقونات: `tools/android/make-icons.mjs` (تُعيد التوليد) ثم `tools/android/res/`
- الشاشة الأولى والألوان: `client/src/index.css` و `client/src/screens/*`

## 5) القوانين المطبَّقة في اللعبة

- 4 لاعبين، **الشركاء متقابلان** (كل لاعبين متواجهين فريق واحد) — يمكن اختيار المقعد عند الدخول.
- 52 ورقة، 13 لكل لاعب، اللعب عكس عقارب الساعة، الترتيب A > K > Q > J > 10 … 2.
- **المزايدة**: من 7 إلى 13، كل طلب أعلى من السابق، والتمرير يُخرجك من المزاد نهائياً.
- الجميع مرّر → **إعادة توزيع** بنفس الموزّع.
- الفائز بالمزاد يختار **الطرنيب** ويلعب أولاً.
- **يجب اتباع اللون** إن كان بحوزتك، وإن لم يكن فأنت حر (الطرنيب غير إلزامي).
- الأكلة للأعلى طرنيباً، وإلا للأعلى من لون البداية.
- **النقاط**:
  - نجاح الطلب (7–12): نقاط = عدد الأكلات، والفريق الآخر صفر.
  - فشل الطلب: الخصم يسجّل أكلاته، والمعلن يخسر قيمة الطلب (المضاعفة ×2).
  - **الكبوت** (13 أكلة بطلب أقل من 13): +16.
  - **طلب 13 ناجح**: +26 • **فاشل**: −16 ومضاعفة أكلات الخصم.
  - المضاعفة (دبل) متاحة عند التفعيل، والفائز أول من يصل للهدف (31 / 41 / 61).
- **المضاعفة (دبل)**: يطلبها الفريق الخصم أثناء المزاد لمضاعفة النقاط.

## 6) ميزات التطبيق

- نظام عضوية: تسجيل / دخول / **زائر** فوري، مستويات وخبرة، عملات، مكافأة يومية.
- إنشاء طاولة أو **لعبة سريعة** أو انضمام برمز، وطاولات خاصة، ودعوة الأصدقاء (مشاركة الرمز).
- إضافة بوتات لإكمال الطاولة، وتبديل المقاعد، وطلب الشراكة.
- دردشة داخل الغرفة + عبارات سريعة + إيموجي.
- أصوات: مؤثرات مولّدة رقمياً (بدون ملفات محمية بحقوق) + أصوات معلّق اختيارية في `client/public/sounds/voice`.
- حركات: توزيع الورق، حركة الأوراق، مؤقت الدور، احتفال الفوز (قصاصات).
- **تدريب ضد البوتات** بدون إنترنت (نفس القوانين).
- تصميم متجاوب بالكامل مع الجوال، وواجهة عربية RTL.

## 8) ملاحظات فنية

- الاتصال بالخادم عبر JSON + توكن `Bearer` (يُخزَّن محلياً)، وجلسات في جدول `sessions`.
- مزامنة الطاولة بـ **Long Polling** مع إعادة اتصال تلقائية وتحديثات متفائلة (تظهر ورقتك فور الضغط).
- كل الطلبات تُمرَّر عبر `/index.php?r=<route>`، و`Router` يعالج CORS و OPTIONS.
- أدوات التطوير تعمل بدون PHP مثبّت (PHP 8.4 عبر WebAssembly) لاختبار نفس ملفات الإنتاج.
- الرسومات والأصوات أصلية (مولّدة داخل المشروع) — لا تُضِف ملفات محمية بحقوق النشر.
