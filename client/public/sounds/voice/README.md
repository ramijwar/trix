# أصوات المعلّق (اختيارية)

التطبيق يعمل بمؤثرات صوتية مُولَّدة رقمياً. إذا رغبت بإضافة تعليق صوتي عربي،
ضع ملفات MP3 بهذه الأسماء بالضبط داخل هذا المجلد:

| الملف | متى يُشغَّل |
|---|---|
| welcome.mp3 | عند تسجيل الدخول |
| good_luck.mp3 | بداية المباراة |
| your_turn.mp3 | عندما يأتي دور اللاعب |
| trump_s.mp3 | إعلان الطرنيب بستوني |
| trump_h.mp3 | إعلان الطرنيب كوبا |
| trump_d.mp3 | إعلان الطرنيب ديناري |
| trump_c.mp3 | إعلان الطرنيب كبة |
| trump_nt.mp3 | إعلان بدون طرنيب |
| kaboot.mp3 | عند تحقيق الكبوت |
| well_played.mp3 | عند الفوز بالجولة |

ثم أعد البناء: `npm run build` (أو `node tools/android/build-apk.mjs` لملف APK).

ملاحظة مهمة: استخدم ملفات صوتية تملك حقوقها أو مولّدة خاصة بك — لا تنسخ أصواتاً جاهزة من تطبيقات أخرى.
